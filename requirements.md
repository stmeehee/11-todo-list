# TODO-LIST PROJECT
- using HTML, CSS & JS
- bundled usign Webpack

## MVP requirements
### capabilities of a todo-object/subtask
1. name/title of todo
2. add a description
3. change due date and time 
4. add priority tag
5. an option to add notes
6. option to add it to a parent task from creation screen 
7. expand todo to see its desc./details
- an option for adding an image as an task background/attachment (optional)

### categorize the todo's into projects/parent task
1. add categories such as 
- generic-tasks
- my-projects
- deleted tasks 
2. create custom parent task/project and change its name

### add a deleted task section
1. where deleted todos can be restored
2. option for permanant deletion
3. quick clear all option

### search for todos
1. search by title/name of todo
2. search in deleted, my-projects or generic-tasks

### sort tasks 
1. by due date 
2. by priority tag 
3. by completed

### some convenient quick-select options at top bar such as
1. show all tasks

### must have:
1. dark mode!
